Controller API reference

Global inside student functions

state, params, and memory are automatically available in every custom function. You do not need to declare them or pass them to helpers.

Standard callbacks

init()
Optional. Called once per fresh experiment to initialize memory.
controller()
Required. Called every params.dt. Return a scalar power in percent or { power }.

Temperature setpoint (°C)

Simulation time (s)

Previous commanded heater output (%)
state.delayedPower
Average delayed power acting over the previous sample (%)
state.ambient
Ambient temperature (°C)
state.disturbance
Equivalent thermal-load offset (°C)

Maximum heater command (%)

Ambient temperature (°C)

memory · student updates

memory begins as {} on every fresh experiment and persists between controller() calls. It does not initialize your custom properties to zero. Use init() to initialize integrals, previous errors, observer states, or other variables.

function init() {
  memory.integral = 0;
}
function controller() {
  // Update memory yourself.
  return 0;
}

The heater is one-directional: returned power is clipped to [0, params.uMax]. The simulator updates physical temperature automatically. Pause/resume keeps memory; Reset, parameter changes, Apply & reset, and each test reinitialize it.

03 / PLANT & EXPERIMENT

Configure your process

τ · dT/dt = −(T − Ta) + K · u(t − L) + d(t)

A first-order thermal process with pure dead time. The controller output u is heater power in percent; d(t) represents an equivalent temperature disturbance.

Ts = 0.2 s · L = 6.0 s

How the FOPTD plant is stepped

The delayed heater command is held constant between controller samples. The simulator computes the exact thermal response for each constant-input interval:

Tk+1 = Teq + (Tk − Teq) e−h/τ

where T_eq = ambient + K · delayedPower + disturbance and h is the interval duration. If a delayed command changes inside a sampling interval, the interval is split into two exact updates. The delay is not rounded to a whole number of samples.

Heater power cannot be negative, so cooling happens passively toward ambient temperature. The model is an educational abstraction, not a physical safety controller.
